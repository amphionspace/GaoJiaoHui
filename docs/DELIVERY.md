# 修复与交付验收记录

日期：2026-10-19。本轮未推送、未替换线上部署，保留已有修改。修改前工作区快照位于 `/tmp/gaojiaohui-before-product-20261019.tar.gz`，不含私密配置。

## 已修复

- 切模块、隐藏页面、离开和换密钥时停止当前会话，迟到的连接、录音权限和合成结果不能启动旧任务。
- 多人工作台正确收集 PCM 数组，不再把回调当作数组；拒绝不足时长的录音，取消后不保存片段。
- 连接与识别收尾均有时限，已收到的文字保留，收尾异常提示核对最后一句。
- 首条临时转写立即显示，重复 final 不再重复插入与合成。
- 克隆对话停止时取消合成和播放等待，长文本分段不截断，播放失败显示错误，缓存有上限。
- 手记补录可替换失败的参考录音；失败保留原文和手记；后台收尾不再卡在生成页。
- 完整原文送入模型，摘要去口癖并保留转折与不确定性；未来回信回应具体细节，单独事实审校，失败不以固定套话代替结果。
- 文本接口鉴权、上传限制、频率及并发限制；默认只监听本机；异常不回显完整连接信息。
- 健康检查不再把 HTTP 500 标记为可用；语音地址通过运行配置下发，密钥不进入响应。
- 补齐依赖、组件生命周期测试、CI、统一启动脚本、生产托管和回滚说明。

## 验证范围

当前本机验证：42 项前端测试、14 项后端测试通过，Vite 7.3.7 生产构建通过，npm 完整依赖审计为 0 漏洞。依赖安装按锁文件及固定 Python 版本清单完成。真实 DeepSeek 五组测试通过并人工检查，页面的文字输入、摘要/回信、标题修改与保留原文已实测。实测页面宽度 480、702、1200 像素，无横向溢出；浏览器视口下限未覆盖 390 像素，仍需在实际手机验收。

前端覆盖完整原文、修改、采样、清理、配额、输出解锁、取消/暂停/恢复、补录、切页和迟到请求。后端覆盖结构/口癖/原文依据、错误重试、凭据保护、鉴权、限流、并发回收、分块上传限制和 TLS/SNI。

真实模型五组虚构样例见 `docs/validation/llm-2026-10-19.json`，包含关心家人、想法转折、悲伤、试音、夹带指令。自动校验后仍需人工阅读，不能承诺模型永不产生事实偏差。
