# 未来手记旅程验证记录

设备规格：32 英寸竖屏，2160 × 3840。改动范围为未来手记旅程及对应测试，保留其他模块与原有工作区修改。该记录形成时尚未更新线上部署；demo1 后续上线记录见 [demo1 发布记录](../DEMO1.md)。

## 行为调整

- 首页不自动打开麦克风；选择主题后点击“开始说话”才进入录音页。
- 等识别服务就绪后才启动录音，分别显示连接、录音及已收到音频状态。
- 录音过程中显示完整转写，按分段标识更新临时结果、最终结果，避免重复插入。
- 即使尚未返回临时文字，收到音频后也能点击结束，提交音频并等待整段识别完成。
- 用户选定的主题保持不变；文字输入入口可直接进入编辑。
- 竖屏使用单列布局，4K 下放大文字、按钮和手记预览；保留电脑尺寸和纸张打印样式。

## 问题定位

旧网关 `/asr/v1/realtime` 可以连接并返回 `session.created`，但测试录音没有产生转写；提交后返回 `Realtime transcription temporarily unavailable` 并断开连接。

未来手记的录音器已改用现有现代网关的 `/asr/v1/target-dialogue`，开放识别模式、空参与者列表、16 kHz 单声道 PCM。该接口实测返回 `transcription.partial`、`transcription.final` 和 `session.done`。其他模块的接口选择保持原样。

## 实测

使用 13.1 秒合成中文录音，通过浏览器中的真实录音器连接实际网关。内容涉及高交会看到帮助老人拿药的机器人，以及为父母制作服药提醒工具的想法。

- 实时显示完整识别内容；点击完成后收到正常结束事件。
- 真实 DeepSeek 返回与录音一致的摘要和针对具体想法的未来回信，页面进入手记预览。
- 4K 竖屏截图检查：首页三个主题、开始按钮和声音选项可见，图片正常加载，没有文字重叠。
- 48 项前端测试通过，覆盖主动开始、服务就绪、多段转写、最终修正、识别失败及取消；Vite 生产构建通过。

以上是首轮验证，声音链路的后续修复与实测见下文。

## 背景声与音色创建修复

第二轮排查定位了以下原因：

- 原录音器按固定音量阈值判断人声，非人声噪声也会触发；停顿只显示暂停，没有自动整理。
- 服务端缺少 `python-multipart`，上传表单在请求百炼之前就返回 HTTP 500。
- 表单上传对象是 Starlette 的 `UploadFile`，原来的子类类型判断会误拒绝有效上传。
- 百炼的 `preferred_name` 最多 16 字符，原代码提交了 39 字符的本地编号；百炼生成的音色编号也与本地编号不同，必须保存映射用于合成和删除。

现在浏览器本地运行 Silero VAD v5，非人声帧用静音替换后送识别，保留语音前后的短缓冲。音色样本只累计通过人声检测的讲话及短暂停顿。听到讲话且已有文字后，持续 8 秒没有人声便自动整理，最后 3 秒显示倒计时；继续说话会取消倒计时。

百炼适配器使用独立的临时音色映射，绑定访问密钥的摘要；原始录音与密钥不写入映射库。录音转换为 24 kHz 单声道 WAV，提交短名称，将返回的真正音色编号用于合成与删除。当前业务空间实测可用模型为 `qwen3.5-omni-plus`，无需另行填写密钥。转换采样率不代表恢复原采样中没有的高频细节。

本轮验证结果：

- 浏览器真实 Silero 推理：3 秒非人声测试音没有触发人声；约 13 秒讲话得到 392 个通过检测的帧；讲话后持续 10 秒非人声测试音，稳定后的人声帧为 0。
- 页面实际连接 ASR、DeepSeek 和百炼，在测试讲话之后持续输入背景测试音，自动结束、生成手记、创建音色，并进入“正在播放 · 我的声音”，没有点击结束或播放按钮。
- 独立真实 HTTP 路由实测：创建音色 200、合成 200，返回 11.44 秒、24 kHz WAV；删除测试音色 200。浏览器测试结束后临时映射记录为 0。
- 51 项前端测试、17 项后端测试及生产构建通过，新增实际 multipart 上传路由、音色编号映射、越权音色隔离、无效录音、人声门限、停顿自动结束与恢复讲话覆盖。人声检测模型与推理资源随构建输出，运行时不依赖外部 CDN。

实测使用合成中文样本，没有代替现场本人录音验收。上述噪声测试不能代表所有展会背景音乐或旁人讲话；本人音色相似度和现场麦克风仍需在设备上确认。保留手动结束和文字输入入口。

接口依据：[百炼声音复刻](https://help.aliyun.com/zh/model-studio/qwen-omni-voice-cloning)、[Silero 浏览器 VAD](https://docs.vad.ricky0123.com/user-guide/api/)。
