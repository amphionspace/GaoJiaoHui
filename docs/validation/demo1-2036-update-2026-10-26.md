# demo1 · 和 2036 对话更新验证

## 本次范围

- 首页标题改为“和 2036 对话”，并在竖屏 2160 × 3840 预览中放大标题、说明和操作文字。
- 开始通话后播放四段无配乐人声故事，画面依次展示耳机、AlphaGo 围棋、无人驾驶汽车和红色跑车进入太空；解说完成后才进入录音。
- 故事页只保留“对 2036 的期待”和必要的跳过、重播、文字入口。
- 整理结果先生成摘要与回信，再根据摘要生成黑白简笔画；小票上方为票据，打印按钮位于票据下方。
- 取消结果页重复展示的回信、原始讲述和底部 FUTURE CALL 文案。

## 生成链路

文本模型新增 `sketch_prompt` 字段，把用户期待转换成可视化的具体场景；图片接口使用工作区已有的百炼配置和 `qwen-image-2.1-turbo`，图片只在服务端下载后以受限的 PNG data URL 返回给当前页面，不把厂商密钥交给浏览器。

图片下载只接受 HTTPS 的阿里云对象存储域名、拒绝跳转、限制 8 MiB，并检查 PNG 文件头。图片生成失败时保留摘要与回信，可单独重试插画，不重复调用文本模型。

## 本地验证

- `frontend`: `npm test`，66 项通过。
- `frontend`: `npm run build`，通过。
- `server`: `.venv/bin/python -m unittest discover -s server -p 'test_*.py'`，41 项通过。
- 百炼图片接口真实调用成功。具体场景提示词生成了“机器人与父母同行”的黑白线稿，并在结果小票中显示。
- 四段故事 WAV 由 `qwen3.5-omni-plus` 直接生成，没有混入背景音乐；时长约为 12.96、11.68、12.88、20.32 秒。
- 浏览器已打开本地 `?view=portrait`，确认首页、故事画面、文字入口、摘要、回信、简笔画和打印按钮；当前浏览器麦克风权限仍被拒绝，因此本轮不宣称现场真人录音和本人音色相似度已验收。

## 事实校对

故事文案将 AlphaGo 表述为在围棋领域击败李世石，AirPods 表述为 2016 年发布，红色 Roadster 表述为 2018 年随 Falcon Heavy 进入太空；无人驾驶表述为已在部分城市提供服务，避免过度概括。
